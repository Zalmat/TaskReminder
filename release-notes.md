# v1.7.0

- Автоматический импорт каталога подстановки из YAML: проекты, задачи и типы работ. Это нужно для упрощения добавления названий из внешних систем (если кто-то захочет добавить себе автоматизацию)
- Новый раздел «Настройки → Задачи»: файл, «Создать пример…», сброс, импорт при запуске и ежедневно по расписанию 
- Небольшие улучшения безопасности и корректности ввода: импорт только существующих `.yaml`/`.yml`, безопасный разбор YAML
- Длинные названия: перенос в списках подстановки (до 480 px) и в таблицах (до 3 строк с многоточием), полный текст — в подсказке при наведении 
- Уведомление 🔔 в окне (тряска около минуты, остановка по клику) и сообщение в трее
- Кнопки «📂 Загрузить категории задач из YAML» и «📄 Скачать шаблон YAML» в главном окне
- Локализация новых разделов: ru / en / de / bg
