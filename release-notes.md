# v1.8.0

## Праздники и календарь 
- Добавлен раздел «Праздники»: несколько событий на одну дату, ежегодные и разовые события, тип и источник.
- Добавление, редактирование и удаление праздников; имя обязательно, дубликаты пропускаются. 
- Старый формат `holidays.json` автоматически мигрирует в новый с сохранением резервной копии `holidays.json.bak`.
- Добавлен импорт календаря из YAML: выбор файла, шаблон, предпросмотр, добавление без дублей.
- В недельном виде типы событий отображаются точками над датой; заголовки колонок выровнены, добавлен общий tooltip.
- Фон и цвет праздников убран, редактирование часов не блокируется, переработка по-прежнему выделяется красным.
- Обновлена локализация ru/en/de/bg. 

## Учёт времени
- Часы в записи ограничены диапазоном 1-24, в ячейке недели - 0-24.
- Отрицательные, нулевые и превышающие лимит значения больше не сохраняются.
- В недельной таблице некорректное значение показывает предупреждение и возвращает предыдущее.
- Сохранены подтверждение переработки, красная индикация и недельный лимит 48 часов.

## Надёжность данных
- Сохранение файлов стало атомарным: временный файл, `fsync`, атомарная замена.
- Ошибки записи больше не проглатываются: приложение показывает ошибку, а не ложное «успешно».
- Память обновляется только после успешной записи; при сбое данные остаются прежними.
- Добавлены резервные копии `.last-good` и восстановление повреждённых JSON.
- Повреждённый файл сохраняется как `.corrupt-*`; при отсутствии резервной копии приложение останавливается с понятной ошибкой и не перезаписывает данные.
- Импорт каталога отмечается как выполненный только после успешного сохранения.
- Добавлены версия схемы `storage.meta.json`, backup перед миграцией и автоматическое восстановление при ошибке.
- Хранятся 5 последних миграционных backup’ов в `backups/`.
- Legacy `.dat` и старый формат праздников мигрируют автоматически. .

## Внутренние изменения
- Диалоги, импорт, подсказки и режим отображения вынесены в отдельные UI-компоненты.
- Сервисы работают через repository-интерфейсы, а не напрямую с JSON-файлами.
- Добавлены тесты на миграции, отказ записи, восстановление, repository-слой и граничные значения часов.

## Обновление
- При первом запуске существующие данные автоматически копируются в бэкап.
- Если приложение сообщает о повреждённом файле, рядом появятся `.corrupt-*` и, при возможности, восстановление из `.last-good`.
