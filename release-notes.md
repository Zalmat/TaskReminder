# v1.7.0

- Автоподстановка в полях «Проект» и «Задача»: поиск по мере ввода, подсветка совпадений, выбор стрелками ↑/↓, полный список по пустому полю/стрелке и свободный ввод
- Подсказки учитывают историю за выбранный срок (по умолчанию 24 месяца) и задачи, которые уже использовались с выбранным проектом
- Новый раздел «Управление подстановкой»: проекты, задачи и типы — ручное добавление, удаление, очистка, источник, частота и последняя дата использования
- Новые значения в менеджере поднимаются наверх, чтобы не потеряться при добавлении нескольких десятков
- Фоновая индексация порциями, без блокировки окна; при длительном построении — спиннер и прогресс-бар
- Автоматический импорт каталога подстановки из YAML: проекты, задачи и типы работ — для интеграции с внешними системами
- Настройки → «Задачи»: файл, «Создать пример…», импорт при запуске и ежедневно, «История для подсказок заголовков (срок жизни)»
- Длинные названия: перенос в списках (до 480 px) и в таблицах (до 3 строк с многоточием), полный текст — в подсказке при наведении
- Уведомление 🔔 в окне (тряска около минуты, остановка по клику) и сообщение в трее
- Кнопки «📂 Загрузить категории задач из YAML» и «📄 Скачать шаблон YAML» в главном окне
- Небольшие улучшения безопасности и корректности ввода: импорт только существующих `.yaml`/`.yml`, безопасный разбор YAML
- Локализация новых разделов: ru / en / de / bg
