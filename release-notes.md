# v1.6.0

- Добавлено автообновление: приложение проверяет релизы, скачивает архив и устанавливает его через внешний апдейтер с сохранением данных Диалог обновления и окно-пасхалка теперь оформляются в выбранной теме (тёмная/светлая)
- Апдейтер запускается из временной копии, делает бэкап и откат при ошибке; для Windows и Linux
- Кнопки «Обновить» и «Скачать zip» в окне обновления
- Режим разработки для тестирования обновления (dev.flag / аргументы / системные свойства)
- Сборка релиза теперь включает апдейтер (Go)
